# Palmi — Learn English with your hands

Обучающая компьютерная игра: игрок показывает жесты американского языка жестов (ASL) перед веб-камерой, ИИ распознаёт форму кисти, а каждое слово связано с английским названием и русским переводом. Путешествие по пяти островам Архипелага Ладоней вместе с выдрёнком Palmi и ИИ-помощником Lumo.

Командный проект по дисциплине «Управление IT-проектами», тема №28 «AI-Языковое приключение».

## Запуск

Нужен **Node.js 20+** (https://nodejs.org, версия LTS) и веб-камера.

```bash
npm install      # ставит Electron и MediaPipe Hands (модель распознавания руки входит в пакет)
npm start        # открывает игру в окне приложения
```

* `npm run dev` — то же, но с инструментами разработчика.
* `npm test` — автотесты логики (классификатор, kNN, адаптивные уровни).
* `npm run test:robust` — устойчивость классификатора к шуму на синтетических руках.
* `npm run build:artifact` — однофайловая демо-версия без камеры (`dist/palmi-demo.html`).

После `npm install` интернет не нужен: модель MediaPipe лежит в `node_modules/@mediapipe/hands`. Шрифт Nunito загружается из Google Fonts; без интернета используется системный шрифт.

**Без камеры** игру можно пройти в демо-режиме: «Настройки → Демо-режим без камеры». В уроке появится панель «Покажи жест»: кнопки подставляют синтетическую руку нужной формы.

## Как работает распознавание

1. **Камера → MediaPipe Hands** даёт 21 ключевую точку кисти (x, y, z) на каждом кадре, точки сглаживаются между кадрами.
2. **Признаки** (`features()`): сгиб каждого пальца (по углам в суставах и по расстоянию кончика до запястья), положение большого пальца, касания большого пальца с кончиками, разведение пальцев. Все признаки нормированы на размер ладони, поэтому не зависят от расстояния до камеры, поворота и того, левая рука или правая.
3. **Шаблоны** 13 слов — наборы диапазонов признаков с весами. Уверенность — взвешенное геометрическое среднее совпадений: один «не тот» палец сильно её снижает.
4. **Калибровка kNN**: игрок записывает 3–8 примеров своих жестов; итоговая уверенность = 0,5 × правила + 0,5 × kNN.
5. **Решение** (защита от ложных срабатываний):
   * первые 1,2 с задания (и 0,6 с между словами предложения) — «Приготовься», кадры не учитываются;
   * рука должна быть в кадре ≥ 0,3 с и почти неподвижна (смещение точек < 3,5% ладони за кадр) — переходные позы не засчитываются;
   * целевой жест должен быть первым с отрывом ≥ 5% от второго;
   * окно голосования: жест верный минимум в 75% из последних 12 кадров;
   * удерживать 0,9 / 1,0 / 1,1 с (Beginner / Intermediate / Advanced).
6. **Разбор ошибок** (`diagnose()`): какие условия шаблона нарушены сильнее всего → подсказка «Указательный палец согнут — выпрями его» и подсветка пальца на рисунке.

Шаблоны настроены на синтетических руках (`synthHand()`) и проверены автотестами. На живых руках точность нужно измерить в «Тесте ИИ» и при необходимости подправить диапазоны в `TEMPLATES` или записать калибровку.

## Структура

```
index.html            точка входа
electron/main.js      окно приложения, разрешение камеры
css/style.css         стили, сцена 1280×720
js/core/              логика без интерфейса: жесты, kNN, контент, адаптация, сохранение
js/ui/                графика (Palmi, Lumo, жители, рисунок руки), звуки
js/vision.js          камера и MediaPipe; демо-режим
js/app.js             навигация, меню, карта, результаты, Premium, статистика, словарь, настройки
js/lesson.js          урок, работа над ошибками, калибровка, тест ИИ
tests/                автотесты
tools/                сборка демо-артефакта
```

## Если камера не включается

* Windows: «Параметры → Конфиденциальность → Камера» — разрешить доступ классическим приложениям.
* Закрой другие программы, которые используют камеру (Zoom, Teams, браузер).
* В «Настройках» игры выбери другую камеру; при ошибке игра сама переходит в демо-режим.

Видео с камеры обрабатывается только на этом компьютере и никуда не отправляется. Сохраняются только числа: прогресс, статистика и точки калибровки.
